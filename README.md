# Жёлтый ТСД: загрузки

Приложение для Android, которое превращает смартфон или бюджетный терминал
сбора данных в ТСД для 1С: инвентаризация, приемка, отгрузка, маркировка.
Базу 1С не нужно публиковать в интернет: входящих соединений в нее нет.

Сайт: https://yellowtsd.ru

В этом репозитории только дистрибутивы (APK, контрольные суммы, описание
версий). Исходного кода здесь нет.

### Установка

1. Скачайте APK на телефон и откройте его.
2. Разрешите установку из этого источника, когда Android спросит.
3. Отсканируйте QR из кабинета или введите код привязки: устройство привяжется к вашей базе 1С.
4. Войдите по PIN кладовщика.

## Что умеет 0.1.0

- Свободная инвентаризация: сканирование камерой, Bluetooth-сканером
  (режим клавиатуры) или ввод кода вручную; количество, комментарий.
- Работа без связи: документ хранится на устройстве, известные товары
  распознаются из кэша, неизвестные коды ждут сопоставления.
- Отправка в 1С с честным состоянием: принято, отправляется, записано,
  отказано, требует разбора.
